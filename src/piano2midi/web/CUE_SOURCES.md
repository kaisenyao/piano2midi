# Cue audio provenance

`cue-active.mp3` and `cue-paused.mp3` are the user's selected ChatGPT desktop
reference sounds, converted to MP3 from the locally installed application's assets:

- `realtime-start-5e7635a2bb70.wav`
- `realtime-end-931ae709daff.wav`

The application bundle references these as realtime voice start/end cues. The
waveform, timing and level were retained during conversion; these are not the
earlier synthesized drafts. No app code or credentials are bundled with the clips.

These are third-party product assets, not newly authored piano2midi audio. This
repository does not supply a redistribution license for them or relicense them
under its MIT license.
